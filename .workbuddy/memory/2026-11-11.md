## 1. TV 端缩略图不显示（根因 + 兼容链）
- 根因不是缓存优先级，而是 TV 图片链路更脆弱：TLS 套件协商、`Accept` 带 AVIF/WebP 时 CDN 返回 TV 无法解码的格式 / 畸形状态行、HTTPS 图床协议异常，加上一次失败被写进 6h 负缓存后长期不重试。
- 诊断日志样本（`adb logcat -s ImageLoader:W`）：`viptulz.com` SocketTimeoutException；`p.lztutu.com` webp 解码失败 + `ProtocolException: Unexpected status line: pe: image/webp`。
- 改动：`ImageLoader` TV 负缓存 TTL 10min、`retryFailed()` 清 `covers_failed/` 与熔断表、`loadBitmapWithRetry()` 多兼容链（去 AVIF → legacy jpeg/png → HTTPS→HTTP → TV 放宽超时，25s 总时限）；`SiteHttpClient` 增加 `ConnectionSpec` 三组、`imageClientRelaxed`、`relaxedTimeout/legacyFormat`；`HtmlParser.coverFromImg()` 补 `data-src`/`data-lazy-src`/`srcset` 与占位图过滤；设置页新增「重试封面」按钮。
- 新增 `HtmlParserCoverTest` 2 个单测，总数 30 → 32。
- 本机无 TV 真机 / TV AVD，兼容链只做代码 + 手机 AVD 侧验证，上盒子后需复验。

# 第十五轮（10:41 用户新需求，2 项）

## 1. 网络失败提示页增加返回按钮
- 根因：`activity_main.xml` 的 `overlay` 是 `match_parent` 且不透明，`StatusFragment` 错误态把下层标题栏 `btn_back` 完全盖住，TV 用户只能靠硬件返回键（且硬件返回只 `clearOverlay()`，露出空白下层）。
- 改动：`StatusHost` 新增 `onStatusBack()`；`BaseTvActivity` 默认实现 `clearOverlay() + if (this is MainActivity) showHome(false) else finish()`，并打 `Log.i("YuJianTV", "状态页返回：X → 上一级")`；`MainActivity` 覆写为 `CrashHandler.clear(this)` + `showHome(false)`；`fragment_status.xml` 的 actions 行最左加 `btn_status_back`（返回图标 + `nextFocusRight=btn_retry`），`btn_retry` 补 `nextFocusLeft`；`StatusFragment` 绑定点击。加载态 `actions` 仍 `gone`，重试/换地址/恢复默认逻辑不变。
- 实机证据（Pixel 3a API 34，飞行模式 + pm clear）：
  - 断网冷启动错误页可见 `! / 网络连接失败 / 返回 / 重试 / 更换地址 / 恢复默认地址`，`btn_status_back` 可聚焦；点击日志 `状态页返回：MainActivity → 主菜单`；恢复网络后再点，首页网格出现且错误页消失。
  - 断网从首页进详情 → `DetailActivity` 错误页 → 点返回，日志 `状态页返回：DetailActivity → 上一级`，顶层切回 `MainActivity`，首页可见。

## 2. 播放页返回/设置按钮与剧集信息等高
- 根因：`play_title`（14sp + 8dp padding → wrap_content）与 `TvChip` Button（12sp + 7dp 纵向 padding + Button 默认 minHeight）高度不同。
- 改动：新增 `dimen/top_chip_height=36dp`（对齐 `activity_main.xml` 标题栏返回按钮）；`activity_playback.xml` 的 `btn_back_top` / `play_title` / `btn_cast` / `btn_settings` 统一写死该高度；两个可见 Button 加 `minHeight=0dp`、`paddingTop/Bottom=0dp`；`play_title` 换 `bg_overlay_chip`、`gravity=center_vertical`、左右 12dp 内边距。
